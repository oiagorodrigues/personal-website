# Iago Rodrigues — personal website

A static personal website with Portuguese, English, and Spanish content, light/dark/system themes, professional experience, and an engineering technology atlas.

## Vercel

Import this repository into Vercel. The included `vercel.json` selects the **Other** framework preset, skips install and build commands, and serves the ready-to-publish files in `dist/`. No package manager or framework runtime is needed.

The Vercel project should use this repository's root directory. After this pull request is merged, select `master` as the production branch if Vercel has not already selected it.

## Local preview

Serve `dist/` with any static HTTP server. No dependency installation is required.

## Assets

The portrait, résumé PDF, favicon, and technology icons are included in `dist/`. Icon licenses are in `dist/tech-icons/`.
